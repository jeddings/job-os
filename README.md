# The Job Search Operating System

**[jeddings.github.io/job-os](https://jeddings.github.io/job-os)**

A documented system for running a Staff-level job search at scale. Built during a five-month search following a January 2026 layoff from Meta, it assessed 471 roles, generated 675 career page check-ins, and produced three simultaneous offers.

The core insight: instead of keyword searches on job boards, the search went directly to company careers pages on a priority-ranked schedule. Instead of evaluating roles by gut feel, a structured 16-column scoring framework produced consistent, comparable assessments. Instead of starting interview prep from scratch each time, a canonical story library and question bank compounded across every stage.

By the end, the system absorbed the complexity. Showing up and doing the work was all that was left.

## What's documented

- **Process flow** — the daily execution loop from company prioritization through career page checks, JD evaluation, gut check scoring, resume tailoring, application or outreach, and all post-application stages through to offer and acceptance
- **Interview prep** — the prep loop triggered by each scheduled stage: role context loading, research, credential gap assessment, domain learning, story selection, mock interviews, and the post-interview debrief that compounded prep quality each round

Every node in both diagrams is clickable and opens a full explanation of that step.
